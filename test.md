# Welcome to My Agents Workspace

This workspace contains several agent implementations for different use cases:

## Available Agents

- **LiteLLM Agent**: An agent powered by the LiteLLM library for flexible language model interactions
- **My Agent**: A custom implementation of a general-purpose agent
- **Structured Agent**: An agent designed for structured, predictable outputs
- **Tool Agent**: An agent specialized in using and managing various tools

## Getting Started

Each agent is contained in its own directory with an `agent.py` file that contains the main implementation logic.

To use any of these agents, import from the respective module:

```python
from litellm_agent import LiteLLMAgent
from my_agent import MyAgent
from structured_agent import StructuredAgent
from tool_agent import ToolAgent
```

## Features

- Modular design for easy integration
- Clear separation of concerns
- Flexible configuration options
- Support for various use cases

Feel free to explore each agent implementation to understand their unique capabilities and use cases.
